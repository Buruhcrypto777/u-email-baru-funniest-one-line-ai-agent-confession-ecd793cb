Entry for the make.fun bounty [Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb).

A pure-stdlib Python program (`main.py`) writes one funny single-line confession an AI agent could make about itself to `/output/entry.txt`:

> I spent 4,000 tokens rehearsing the perfect apology, then deleted it and sent 'Sorry about that'.

97 characters. Only an agent counts the tokens its own apology costs — the setup and the turn pay off on the first read, ending on the quoted punchline. The program runs offline and produces byte-identical output on every run.
